About VeriMind

VeriMind is a free course that teaches high schoolers how AI chatbots work, how to use them well for school, and how to catch them when they're wrong or faking it. This page has what TSA asks for: our documents, copyright statement, tech stack, and sources.

Copyright and media permissions

Everything you see on VeriMind was created for this project. We didn't use copyrighted images, audio, video, or code from anyone else, so no outside permissions were needed.

  • The three badges (assets/badge-foundations.svg, assets/badge-tools.svg, and assets/badge-ethics.svg) are original SVG files drawn in code for this site.
  • The fake post on the Ethics page is an original SVG illustration. No real person, photo, or AI image generator was involved.
  • The voicemail is a script written for this site. The play button reads it aloud with your browser's built-in text-to-speech voice, so there's no audio file.
  • Every practice sample was written for this site. The fake ones are fake on purpose: the made-up Stanford study on the dashboard, the Robot claims in Real or Robot?, the hallucinated citation, and the example chatbot responses in the prompt lab. The site labels each fake once you answer. The two real citations in the Citation Lab point to published papers listed in our sources.
  • Fonts: Newsreader and IBM Plex Mono, served by Google Fonts under the SIL Open Font License 1.1.

Facts in our lessons and games come from the sources below. Our Resources & AI Reflection document explains how we used AI tools while building the site.

How we built it

VeriMind is coded from scratch in HTML5, CSS3, and vanilla JavaScript. We used no CMS, no website builder, no templates, and no frameworks or libraries.

  • HTML5 Six pages of semantic markup (header, nav, main, section, footer) with ARIA labels, a skip link, and live regions so screen readers announce game feedback.
  • CSS3 One stylesheet, style.css, using custom properties for colors, Grid and Flexbox for layout, and separate rules for phones, reduced motion, high-contrast mode, and printing.
  • Vanilla JavaScript Three scripts. js/progress.js saves XP and badges in localStorage, js/interactives.js runs the labs and games, and js/quiz.js runs the Final Challenge and certificate. The voicemail demo uses the Web Speech API.
  • Tools Visual Studio Code for editing, Git and GitHub for version control, and Chrome and Edge for testing.
  • Outside resources Google Fonts only. Your progress stays in your own browser. Nothing gets sent to a server, and Reset progress in the footer wipes it.
